# KaamConnect - AI-Enabled Job Platform for Daily Wage Workers

An innovative web-based employment platform specifically designed for daily wage and semi-skilled workers, connecting them with verified employers through AI-powered matching.

## 🌟 Key Features

### For Workers
- **AI-Powered Job Matching**: Smart algorithms match workers with suitable jobs based on skills, location, and availability
- **Voice-Based Profile Creation**: Create profiles using speech-to-text technology (no reading/writing required)
- **Multilingual Support**: Available in English, Hindi, Bengali, Odiya,Telugu, Tamil, Marathi
- **NGO Verification**: Get verified by trusted NGO partners to increase employability
- **Secure Payments**: Payment protection ensures workers get paid for completed work

### For Employers  
- **Quick Job Posting**: Post jobs in minutes with detailed requirements
- **AI-Matched Workers**: Get matched with verified workers who fit your needs
- **Direct Hiring**: Review profiles, ratings, and hire directly
- **Rating System**: Build trust through mutual rating and reviews

### For NGOs
- **Verification Portal**: Verify both workers and employers
- **Dashboard Analytics**: Track verification statistics and success rates
- **Community Impact**: Help connect workers with legitimate opportunities

## 🚀 Getting Started

### Installation

1. Extract the ZIP file to your desired location
2. Open `index.html` in a modern web browser

### Usage

**For Workers:**
1. Click "Register" and select "I'm a Worker"
2. Fill in your details (or use Voice Profile)
3. Browse jobs or let AI match you with suitable opportunities
4. Apply to jobs and get hired!

**For Employers:**
1. Click "Register" and select "I'm an Employer"
2. Create your company profile
3. Post job requirements
4. Review matched workers and hire

**For NGOs:**
1. Visit the NGO Portal
2. Login with NGO credentials
3. Verify worker and employer profiles
4. Monitor platform statistics
